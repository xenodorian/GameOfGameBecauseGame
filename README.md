# GameOfGameBecauseGame

## Game
- Changeling: Knight of a thousand faces. Playable build: [game/changeling.html](game/changeling.html). Open the file in a browser. Design notes and build checklist: [Current_Work.md](Current_Work.md).

- The game has 8 levels. Controls: arrow keys to move and jump, A S Z X for your four powers, C to drop a card from your hand, Q to drop your face, Enter to confirm.
