# GameOfGameBecauseGame

## Game
- Changeling: Knight of a thousand faces. Playable build: [game/changeling.html](game/changeling.html). Open the file in a browser. Project notes: [Claude_Notes.md](Claude_Notes.md).

- The game has 8 levels. Controls: arrow keys to move and jump, A S Z X for your four powers, C to drop a card from your hand, Q to drop your face, Enter to confirm.
